## Installation

1. Téléchargez **Tournees-Pollet-Setup.exe** avec le lien ci-dessus.
2. Lancez-le : l'installation se fait pour l'utilisateur courant, sans droits administrateur.
3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**
   puis **Exécuter quand même** (l'installateur n'est pas encore signé par un certificat éditeur).

L'application se met ensuite **à jour toute seule** : à chaque nouvelle version, elle propose de
l'installer au démarrage, puis redémarre.

## Ce que fait l'application

- Import de la liste des clients depuis Excel, localisation automatique des adresses.
- Tournées : choix des clients, ajout d'adresses avec autocomplétion, carte.
- Optimisation de l'ordre de passage au plus rapide ou au plus court, arrêts verrouillables,
  ajustements à la main.
- Feuille de route Excel ou imprimée, horaires de passage estimés.

Les données (clients, tournées) restent sur le poste, dans une base locale.
